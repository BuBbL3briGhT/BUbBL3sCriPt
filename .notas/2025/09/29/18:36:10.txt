Here is a basic "Hello World" program written in C:
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}

Explanation:

• #include &lt;stdio.h&gt;: This line includes the standard input/output library. This library provides functions like printf() for displaying output to the console.
• int main() { ... }: This defines the main function, which is the entry point of every C program. The code inside the curly braces {} is executed when the program runs. The int indicates that the main function returns an integer value.
• printf("Hello, World!\n");: This line calls the printf() function to display the string "Hello, World!" on the console. The \n is a newline character, which moves the cursor to the next line after printing the message.
• return 0;: This statement indicates that the main function has successfully executed and returns a value of 0 to the operating system. A return value of 0 typically signifies successful execution.
