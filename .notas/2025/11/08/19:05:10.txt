Mocha itself is a test runner and does not include a built-in assertion library for checking if a function throws an exception. However, it integrates seamlessly with various assertion libraries, such as Node.js's built-in assert module or third-party libraries like Chai.
Using Node.js's assert module:
The assert module provides a throws method to check if a function throws an error.
const assert = require('assert');

describe('My Function', function() {
  it('should throw an error when invalid input is provided', function() {
    const myFunction = (input) => {
      if (typeof input !== 'number') {
        throw new Error('Input must be a number');
      }
      return input * 2;
    };

    assert.throws(() => myFunction('invalid'), Error, 'Input must be a number');
  });
});

Using Chai's expect or should assertion styles:
Chai offers more expressive syntax for asserting thrown exceptions.
expect style:
const { expect } = require('chai');

describe('My Function', function() {
  it('should throw an error when invalid input is provided', function() {
    const myFunction = (input) => {
      if (typeof input !== 'number') {
        throw new Error('Input must be a number');
      }
      return input * 2;
    };

    expect(() => myFunction('invalid')).to.throw('Input must be a number');
    // You can also assert the error type:
    expect(() => myFunction('invalid')).to.throw(Error);
  });
});

should style:
const chai = require('chai');
chai.should(); // This enables the 'should' style

describe('My Function', function() {
  it('should throw an error when invalid input is provided', function() {
    const myFunction = (input) => {
      if (typeof input !== 'number') {
        throw new Error('Input must be a number');
      }
      return input * 2;
    };

    (() => myFunction('invalid')).should.throw('Input must be a number');
  });
});

Key Points:

• Wrap the function call in an anonymous function or arrow function: When using assert.throws or Chai's expect().to.throw(), you must wrap the function call that is expected to throw an error within another function (e.g., an anonymous function or an arrow function). This ensures that the assertion library can properly catch the exception.
• Specify the expected error type or message: You can optionally provide the expected error type (e.g., Error, TypeError) or a regular expression/string to match against the error message.
• Asynchronous functions: For asynchronous functions that reject with an error (e.g., Promises), you would use assert.rejects (from Node.js's assert) or expect().to.be.rejectedWith() (from chai-as-promised plugin for Chai). [1]
