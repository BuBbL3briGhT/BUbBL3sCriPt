In C, unions are a powerful feature that allows you to store variables of different types in the same memory location. However, only one member of the union can hold a value at any given time. To store and retrieve variables of any type using a union, you can use type casting and careful management of the union's members.
Here’s an example of how to use a union to store variables of different types:
C#include <stdio.h>

typedef union {
    int i;
    float f;
    char c;
    void *ptr;
} AnyType;

int main() {
    AnyType value;

    // Store an integer
    value.i = 42;
    printf("Integer: %d\n", value.i);

    // Store a float
    value.f = 3.14f;
    printf("Float: %.2f\n", value.f);

    // Store a character
    value.c = 'A';
    printf("Character: %c\n", value.c);

    // Store a pointer (e.g., to an integer)
    int num = 100;
    value.ptr = &num;
    printf("Pointer to integer: %d\n", *(int *)value.ptr);

    return 0;
}

Explanation:

Union Definition: The AnyType union can store an int, float, char, or void * pointer.
Type Casting: When storing or retrieving a pointer, you must cast it to the appropriate type (e.g., (int *)).
Memory Sharing: All members share the same memory, so assigning a value to one member overwrites the previous value.

Notes:

Be cautious when using unions, as accessing a member that wasn't most recently assigned can lead to undefined behavior.
If you need to track the type of data stored, consider adding an additional variable (e.g., an enum) to indicate the active type.

This approach is useful for scenarios like implementing a generic container or handling polymorphic data.
