Here’s a simple Makefile to compile a basic C application using gcc. This example assumes your project has a single C source file (main.c) and generates an executable named app.
Makefile# Compiler and flags
CC = gcc
CFLAGS = -Wall -Wextra -g

# Target executable
TARGET = app

# Source files
SRCS = main.c

# Object files (derived from source files)
OBJS = $(SRCS:.c=.o)

# Default target
all: $(TARGET)

# Rule to build the target
$(TARGET): $(OBJS)
	$(CC) $(CFLAGS) -o $(TARGET) $(OBJS)

# Rule to compile source files into object files
%.o: %.c
	$(CC) $(CFLAGS) -c $< -o $@

# Clean up build files
clean:
	rm -f $(OBJS) $(TARGET)

# Phony targets
.PHONY: all clean

How it works:


Variables:

CC: Specifies the compiler (gcc).
CFLAGS: Compiler flags for warnings and debugging.
TARGET: The name of the final executable.
SRCS: List of source files.
OBJS: Automatically converts .c files to .o files.



Targets:

all: Default target that builds the executable.
clean: Removes generated files (.o and the executable).



Rules:

$(TARGET): Links object files into the final executable.
%.o: %.c: Compiles each .c file into a .o file.



Usage:

Save the file as Makefile in the same directory as your main.c.
Run the following commands:

To build: make
To clean: make clean
