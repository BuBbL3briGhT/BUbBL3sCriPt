In JavaScript, objects can be merged using several methods, with the most common being the spread operator (...) and Object.assign().
1. Using the Spread Operator (...)
The spread operator provides a concise and modern way to merge objects. It creates a new object containing all properties from the source objects. If properties with the same name exist in multiple objects, the value from the rightmost object in the spread sequence will override the earlier ones. [1]
const obj1 = { a: 1, b: 2 };
const obj2 = { b: 3, c: 4 };
const mergedObj = { ...obj1, ...obj2 };

console.log(mergedObj); // Output: { a: 1, b: 3, c: 4 }

2. Using Object.assign()
The Object.assign() method can also be used to merge objects. It copies all enumerable own properties from one or more source objects to a target object. The first argument is the target object, and subsequent arguments are the source objects.
If you want to create a new object without modifying any of the original objects, use an empty object {} as the target:
const obj1 = { a: 1, b: 2 };
const obj2 = { b: 3, c: 4 };
const mergedObj = Object.assign({}, obj1, obj2);

console.log(mergedObj); // Output: { a: 1, b: 3, c: 4 }

If you intend to modify an existing object, you can pass it as the target:
const targetObj = { x: 1, y: 2 };
const sourceObj = { y: 3, z: 4 };
Object.assign(targetObj, sourceObj);

console.log(targetObj); // Output: { x: 1, y: 3, z: 4 }

Key Considerations:

• Shallow vs. Deep Merging: Both the spread operator and Object.assign() perform a shallow merge. This means that if an object contains nested objects, only the references to those nested objects are copied, not the nested objects themselves. For deep merging, where nested objects are also recursively merged, you would typically need to implement a custom recursive function or use a library like Lodash's _.merge().
• Immutability: The spread operator, when used to create a new object, is an immutable approach as it does not modify the original objects. Object.assign() can be used immutably by providing an empty object as the target, or mutably by using an existing object as the target.
